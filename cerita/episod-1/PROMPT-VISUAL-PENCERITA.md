# Prompt ilustrasi aksi Pencerita

Dijana dengan alat imagegen terbina dalam. Empat storyboard menggunakan ilustrasi asal sebagai rujukan gaya dan watak; panel diekstrak sebagai aset JPG untuk game dan skrip. Bulatan pen merah ialah lapisan SVG yang dianimasikan dalam game.

Awalan setiap prompt: Use case: illustration-story. Asset type: ONE coherent storyboard texture sheet for a visual novel, matching reference anime artwork, warm detailed painterly backgrounds and expressive school characters. Reference image is style and character identity reference, not an edit target.

Akhiran setiap prompt: Panels are clean full-bleed cinematic art filling every cell; absolute equal divisions and no merged panels. High detail, natural hands, no UI, no watermarks.
